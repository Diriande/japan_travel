# Connectivité - eSIM / pocket wifi

- **eSIM** : solution la plus simple aujourd'hui (Airalo, Ubigi, Nomad...) - forfait data 20 jours ~25-40€/personne, activable avant le départ, pas de carte physique à gérer
- **Pocket wifi** : alternative si téléphones anciens sans eSIM ou pour mutualiser une seule connexion à 2-3 personnes (~6-8€/jour pour l'appareil, à retirer/rendre à l'aéroport) - peut être plus économique pour 3 personnes partageant le même appareil
- **Wifi gratuit** : présent dans beaucoup de gares, konbini et hôtels, mais pas suffisamment fiable pour en dépendre entièrement
- **Recommandation** : eSIM individuelle pour chacun si le budget le permet (plus simple, pas de risque de perdre le signal en étant séparés), sinon un pocket wifi partagé pour un groupe de 3 restant généralement ensemble
