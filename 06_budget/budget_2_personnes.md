# Budget indicatif - 2 personnes (toi + un parent)

Scénario si ton père ne vient pas (ta mère + toi, par exemple). Chiffres pour la version 3 semaines (19 nuits) ; le dashboard permet de basculer sur la version 2 semaines condensée.

## Formule partagée (recommandée pour le budget) — 1 chambre à 2 lits, type Riverside Shinjuku

| Poste | Par personne | Total (2 pers) | Détail |
|---|---|---|---|
| Vol Finnair A/R | 1000€ | 2000€ | 2x23kg inclus en Economy Classic (relevé 515€ le 23/08/2026, hypothèse conservatrice) |
| Hébergement (19 nuits, business hotel économique) | 751€ | 1502€ | Voir `03_hebergement/` |
| Transport de base | 452€ | 904€ | Trajets longue distance + IC card, voir `02_transport/jr_pass_vs_billets.md` |
| Activités/visites | 236€ | 472€ | Voir `05_activites/` |
| Nourriture (20 jours, ~40€/jour) | 800€ | 1600€ | Mix konbini/ramen/izakaya |
| Divers (eSIM, assurance, souvenirs) | 300€ | 600€ | |
| **TOTAL** | **~3539€** | **~7078€** | |

## Avec voiture de location (Takayama → Kanazawa)

Ajoute ~230€ au total du groupe (remplace le bus ~24€/pers), soit ~7260€ (formule partagée) ou ~3630€/pers.

Ces montants sont recalculables en direct dans `dashboard/index.html` selon les activités réellement choisies, la formule d'hébergement, la durée (2 ou 3 semaines), l'option voiture de location et le prix du vol.
