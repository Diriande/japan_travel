# J7-J9 - Kawaguchiko (Fuji Five Lakes, 2 nuits) + Hakone (1 nuit)

## J7 (Jeu) - Tokyo → Kawaguchiko
Bus autoroutier direct depuis Tokyo (~1h45). Installation, puis pagode Chureito si le temps et l'énergie le permettent (vue classique du Mont Fuji avec la pagode au premier plan).

## J8 (Ven) - Kawaguchiko
Oshino Hakkai (village aux sources d'eau claire, sans dénivelé). Croisière sur le lac Kawaguchiko. Option Kachi Kachi Yama Ropeway pour une vue en hauteur sur le lac et le Mont Fuji.

**Note vertige** : le ropeway est une cabine suspendue, courte mais exposée. Alternative : les rives du lac ou le pont Fuji Omuro Sengen offrent une vue similaire sans monter.

## J9 (Sam) - Kawaguchiko → Hakone
Bus via Gotemba (~2h). Owakudani (vallée volcanique, œufs noirs cuits à la vapeur). Croisière sur le lac Ashi avec vue sur le Mont Fuji par temps clair. Installation au ryokan avec onsen pour la soirée.

**Note vertige** : le tronçon en ropeway au-dessus d'Owakudani est très exposé. Alternative : bus Hakone Tozan (au sol) pour rejoindre directement le lac Ashi en sautant ce tronçon.
